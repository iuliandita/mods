# mods

A collection of mods for Claude Code (plugins built on the hooks-module API), some also for Codex and
OpenCode. Each mod is its own plugin, installable on its own. `develop` is the default and nightly
branch (v0.x prerelease); `main` becomes stable at v1.0.0.

If `AGENTS.local.md` exists beside this file, read it too. It holds local paths and preferences and never
relaxes the rules here.

## Commands

```sh
pip install -r requirements-dev.txt
# pre-push set, mirrors CI (CI also runs actionlint, zizmor, gitleaks, lychee)
python3 -m pytest -q -m "not integration"
bun test mods/*/host
scripts/typecheck --hosts
scripts/mods validate --no-claude
scripts/mods generate --check
python3 .github/stack/stack-check.py
python3 scripts/check-plugin-versions.py
npm ci --ignore-scripts --prefix .github/tools/markdownlint
.github/tools/markdownlint/node_modules/.bin/markdownlint-cli2
# regenerate generated files
scripts/mods generate
# need the claude CLI; use a throwaway config dir
scripts/mods validate
python3 -m pytest -q -m integration
# after TypeScript changes
scripts/typecheck <mod>
claude plugin test mods/<mod>/claude
```

## Layout

- `mods/<name>/mod.json` is the source of truth. `.claude-plugin/marketplace.json`, `mods.json`,
  `.agents/plugins/`, copied `hooks/shared/`, injected blocks, and the built `codex/` and `opencode/`
  bundles are generated by `scripts/mods generate`: never hand-edit.
- `shared/` holds helpers and `*.inject.ts` templates; `mods/<name>/claude/` is the plugin and
  `mods/<name>/host/` the Codex and OpenCode adapters. `local/` (ignored) holds private mods.
- `scripts/modslib/` is the CLI package, `tests/` its pytest suite, `.github/` holds CI.
- Details: [CONTRIBUTING.md](CONTRIBUTING.md), [INSTALL.md](INSTALL.md), [docs/](docs/README.md).

## Rules

- Issue first, branch from `develop`, PR into `develop`, conventional commits, `Closes #NN`. Never commit to `main` or `develop`.
- No AI attribution in commits, PRs, tags, or files.
- No private hosts, domains, IPs, machine paths, or work context in tracked files. `scripts/mods validate` scans for some.
- Security mods fail closed: every gating hook needs `.catch`. A guard-rules bypass fix needs a corpus row.
- Secret-box rewrites Bash commands containing a placeholder: write such text with the file tools.
- Security findings get an issue labeled `security` and `p0` to `p3` before the fix.
- Edit in a worktree: a session loads installed mods from the clone's checked-out branch.

## For agents

- `scripts/mods` is the machine-readable CLI: `--json` on every command, exit codes 0 done, 1 failed,
  2 usage, 3 required tool missing. `mods.json` is the catalog. Contract: [INSTALL.md](INSTALL.md#for-agents).
- Install with `claude plugin marketplace add iuliandita/mods` then `claude plugin install <mod>@iuliandita-mods`.
- The pre-push set is the commented block under Commands; `.github/workflows/ci.yml` runs the same.
